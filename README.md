# Bubble Bath Royale

A fun 3D physics-based survival game where you play as a rubber duck, fighting to stay afloat in a chaotic bubble bath. Think bath-time meets battle royale!
Made as part of Global Game Jam 2025.

## Releases
Initial prototype release is available on the [GGJ website](https://globalgamejam.org/games/2025/bubble-bath-royale-6).

Both this repository and the [Itch.io page](https://kreateer.itch.io/bubble-bath-royale) contain an updated version of the game.
